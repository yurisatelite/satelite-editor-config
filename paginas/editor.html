Precisa de ajuda em algum passo?

O arquivo não abriu no Claude? No Claude, vá em Configurações → Extensões → Configurações avançadas → Instalar extensão e escolha o arquivo baixado.

A chave grátis: entre em console.groq.com/keys, crie uma conta, clique em Create API Key e copie a chave (começa com gsk_). Cole no campo Chave de acesso. É uma vez só.

O caminho do vídeo: no Windows, Shift + botão direito no arquivo → Copiar como caminho. No Mac, selecione no Finder e aperte Option + Cmd + C. Vídeo anexado no chat não funciona: o editor lê direto do seu disco.

No Mac apareceu “desenvolvedor não identificado”? Ajustes do Sistema → Privacidade e Segurança → Abrir mesmo assim.

Onde fica o vídeo pronto: na mesma pasta do original, com “ - editado” no nome.

Dúvidas

O que mais perguntam.

Funciona no ChatGPT ou no Gemini?

Não. Hoje o Satélite Editor funciona só no Claude Desktop, o aplicativo do Claude para computador. Não funciona no ChatGPT, no Gemini, nem no Claude pelo navegador ou pelo celular. Antes de comprar, confira se você usa ou pode instalar o Claude Desktop (é grátis).

O meu vídeo sobe para algum lugar?

Não. O corte, a legenda e o render acontecem no seu computador. Só o áudio, comprimido, vai para um serviço de I.A que transcreve a fala e devolve o texto.

Meu computador aguenta?

Qualquer computador razoável dos últimos anos. O render é a parte mais pesada: um vídeo curto leva alguns minutos. Você acompanha a porcentagem e pode continuar mexendo enquanto ele roda.

E se o corte automático errar?

É para isso que existe a ficha. Você vê cada frase, liga e desliga, estica a ponta de um clipe, edita o texto e renderiza de novo. O automático faz a maior parte; você só refina.

Tenho um Mac antigo, com chip Intel.

A versão para Intel ainda não saiu. Os Macs com chip Apple (M1 a M5) já funcionam.
